# The battle look's faces (docs/BATTLE-LOOK.md)

Seven faces from Google Fonts, each under the SIL Open Font License 1.1 (its text in `licenses/`), cut down to the characters the game writes with them (digits, capitals and `! + - − % · :`): the owner chose column C of the sheet of candidates (2026-11-11).

| File | Face | For |
|---|---|---|
| `titan-one.woff2` | Titan One | the floor's writing (WEAK!, STUNNED, the levels); crushing hits |
| `bangers.woff2` | Bangers | slashing hits |
| `barlow-condensed-black-italic.woff2` | Barlow Condensed Black Italic | piercing hits |
| `chakra-petch-bold-italic.woff2` | Chakra Petch Bold Italic | projectile hits |
| `rubik-dirt.woff2` | Rubik Dirt | earthquake hits |
| `cinzel-decorative-black.woff2` | Cinzel Decorative Black | elemental hits |
| `pixelify-sans-bold.woff` | Pixelify Sans Bold | statuses (a WOFF, not a WOFF2: as Google Fonts served it) |

game.html declares them (`BV Titan`, `BV Bangers`, `BV Barlow`, `BV Chakra`, `BV Dirt`, `BV Cinzel`, `BV Pixelify`).
