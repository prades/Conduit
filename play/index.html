What this is. A thin front end around EmulatorJS, which runs the mupen64plus N64 core compiled to WebAssembly. I did not write the emulator — it is a mature open-source project doing the hard parts (RSP vector unit, RDP rasterizer, graphics microcode HLE). The core is fetched from the EmulatorJS CDN on first load, so it needs an internet connection and a few seconds to download.
Controls. On a tablet a touch overlay appears once the game starts: drag anywhere on the left half to steer (the stick homes to your thumb, and feeds real analog values rather than on/off presses), with A/B/Z/L/R, Start and a C-pad on the right. ⚙ CONTROLS at the bottom opens the settings. Input goes out as both a gamepad and key presses, since cores differ on which they read — the panel shows a live gamepad poll count so you can tell which path is live, and every button's pad index and key can be stepped until it lands. Layout and mapping are saved. A paired Bluetooth controller keeps working alongside it.
Performance. N64 in a browser is demanding. A desktop will do better than a tablet, and a native emulator (RetroArch, simple64, Project64, Ares) will beat both.
No ROMs are included. Load a dump of a cartridge you own.
